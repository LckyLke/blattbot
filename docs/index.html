BlattBot

An agentic LaTeX editor that syncs with any Overleaf.

Runs on your machine with your Claude Code login. Overleaf is optional.

\section{proof}

Agent edits land as diffs you approve

The agent works in a local git checkout and compiles after editing to check its own work. You can watch the diff grow during the turn. When it ends, review the changes per file or per hunk. Keep what you want and discard the rest. On a connected project, approved changes are pushed to Overleaf with a normal history entry.

\section{editor}

A full editor on its own

Projects can live entirely on your machine. The editor is CodeMirror with LaTeX autocomplete, including your own cite keys and labels. Saving triggers a compile and the PDF sits next to the source. Double-click a line in the PDF to jump back to the code, or send a sentence from the PDF into the chat.

\section{citations}

Paper search, built in

Search OpenAlex, Semantic Scholar, DBLP, and Crossref from inside the app. Each paper comes with a one-line summary so you can judge relevance quickly. The References tab shows where every entry is cited and flags the ones that never get used. BibTeX import and export are there too.

\section{overleaf}

Syncs with any Overleaf

overleaf.com works, and so does a self-hosted server. BlattBot was first built against a university's own instance. Connect over the git bridge or through your existing browser session. SSO logins work too. You can keep several accounts side by side, and an expired session re-imports itself from your browser. When a local project is ready to share, publish it to Overleaf.

\section{trust}

You can read the whole system prompt

The system prompt sits in a settings tab, and every operating mode shows its full instructions. The server listens on loopback only and requires a token on every request. Secrets live in your data dir with 0600 permissions. Agent turns run on your own Claude Code login. No account, no telemetry.

\begin{enumerate}

How it works

Overleaf (optional) ⇄ local project ⇄ Claude agent (edit → compile → verify)
                             ⇩
               you review the diff → approve → push

  1. npx blattbot

    Starts the local server and opens the app. If there's no TeX engine on your machine, it offers to fetch tectonic, about 20 MB, downloaded once.

  2. Create or connect a project

    Start with a blank local project, or paste an Overleaf link. BlattBot imports the session from your browser, or opens a real login window where SSO works.

  3. Ask, then approve

    Ask for an edit and read the diff. Approve it and it's committed. On an Overleaf project the change is pushed with a proper history entry.

\end{enumerate}

Requires Node 20+, git, and Claude Code (logged in). A TeX engine is auto-installable.
